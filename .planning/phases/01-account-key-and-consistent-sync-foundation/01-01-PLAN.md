# Phase 1 Plan: Account, Key, and Consistent Sync Foundation

## Goal

Bind exactly one local WeChat account, verify its database key and decrypted primary databases, and publish fresh session metadata through an atomic account-scoped generation.

## Tasks

1. Implement Chatlog health, account discovery, account history, and explicit account switching.
2. Implement key acquisition when absent, macOS Keychain round-trip verification, decrypt, and readable primary-database verification.
3. Implement local SQLite account/generation state, staging, atomic publish, and failed-generation preservation.
4. Add JSONL diagnostics, unit tests, live validation, and verified-path documentation.

## Verification

- `scripts/phase1_validate.sh`
- Previous published generation remains published when a staging generation fails.
- No raw database key is emitted by the product CLI or stored in the product SQLite state.
