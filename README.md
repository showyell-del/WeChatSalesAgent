# 微信客户分析 Agent（内测）

面向 macOS Apple Silicon 的本地桌面工具：读取用户明确连接的微信私聊，通过 DeepSeek 完成人物画像、关系洞察、客户经营、话题分析和事件时间线，并导出随任务变化、可追溯到真实对话证据的 Excel、PDF 或文本报告。

## 安装与使用

1. 使用授权的 Apple Silicon 内测 Mac，安装并登录微信。
2. 打开 `dist/WeChatSalesAgent-MVP-macOS-arm64.dmg`，将 App 拖到“应用程序”。
3. 打开 App，点击“关闭 SIP 指引”，按界面步骤进入 macOS 恢复模式完成操作。
4. 重启并再次打开 App，确认左侧显示“SIP 已关闭”，再点击“连接并同步微信”。
5. 保存 DeepSeek API Key，在“智能分析”中直接输入问题并发送。
6. 核对 Agent 返回的分项结论与聊天证据，按需继续追问、保存分析或导出动态报告。

当前 MVP 不包含任何微信消息发送、图片、视频、文件或拖放入口，也不使用剪贴板、键鼠模拟等替代方案。

## 智能分析能力

- 支持连续追问，识别“他”“这些人”等上下文指代。
- 支持客户筛选、成交机会、重新激活、客户风险、承诺待办、人物画像、关系洞察、多人比较、话题分析和事件时间线。
- 结论显示置信度、支持证据与反例；点击证据可查看原始消息及前后文。
- 消息总量、双方数量、活跃天数、发起次数和回复中位时长均由本地程序精确计算。
- 已保存分析以保存时的语料水位为起点，刷新时只处理后续新增消息。
- 导出前可选择格式和内容；Excel 工作表与字段随当前任务改变，图表保持可编辑。

当前包是 ad-hoc 签名的本地内测 MVP，不作为大规模商用发行包。

关闭 SIP 会降低 macOS 系统保护。在替换掉当前密钥提取方案之前，该 MVP 不属于默认 Mac 上开箱即用的普通用户发行版。

## 数据与安全边界

- 原始聊天和分析状态保存在用户本机。
- DeepSeek API Key 保存在 macOS Keychain。
- 只有用户主动发送问题后，本次候选聊天证据才会发送给 DeepSeek。
- 人物画像与关系分析只使用指定联系人的本人发言和可复核互动事实；客户筛选才生成意向与跟进字段。
